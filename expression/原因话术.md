# 原因话术

## 核心表达策略

当前公司只入职 4 个月，离职原因很容易被挑战。回答时不要把重点放在“当前公司不好”或“工作不 AI”，而是放在：

> 当前岗位解决了工程稳定性和基础设施问题，这段经历有价值；但从长期规划看，我更希望主线聚焦在 LLM 应用架构、Agent 能力建设、评测驱动迭代，以及更 AI-native 的产品和业务闭环上。

关键原则：

- 不否定当前公司、团队和业务。
- 承认问题排查、链路治理、工程稳定性是 AI 落地的重要组成部分。
- 强调不是因为适应不了、绩效问题或团队问题离开。
- 强调自己是在谨慎看长期方向更匹配的机会。
- 把未来方向说具体：LLM 工程化、Agent 架构、评测体系、平台化、业务闭环。

## 互联网大厂A公司离职原因

推荐表达：

> 我从互联网大厂A公司离开，主要是因为当时做的是聊天机器人和深度研究智能体，技术探索比较多，但和具体业务落地结合还不够深。我希望把自己在 LLM 工程、Agent、评测和系统化落地上的经验，放到更真实的业务场景里验证，所以选择了现在这份汽车语音助手相关的工作。

更短版本：

> 互联网大厂A公司那段主要偏探索，和业务落地结合不够深，所以我希望把 LLM 和 Agent 相关经验落到真实业务场景里。这也是我选择当前工作的主要原因。

## 当前公司离职原因

推荐主版本：

> 这段经历我最大的收获，是对大模型在车载场景落地的复杂性有了更真实的认识。入职后我承担了 LLM Gateway、评测体系、开放问答和调度链路升级等工作，其中也有不少时间在做线上问题排查、链路稳定性、效果定位和工程治理。
>
> 这些工作很重要，也让我补上了很多真实业务落地里的工程经验。但从长期规划来看，我更希望把主要精力放在 LLM 应用架构、Agent 能力建设、评测驱动迭代，以及更 AI-native 的产品和业务闭环上。
>
> 所以我现在看机会，并不是因为当前公司或团队有问题，而是希望下一段选择能和我的长期方向更一致：在大模型工程化、Agent 架构、评测体系和业务落地上做得更深。

## 更直接的版本

> 当前这段工作让我意识到，真实业务里的 LLM 落地并不只是模型和 Agent 能力建设，也包含大量链路稳定性、问题排查、工程治理和存量系统适配。这些事情我能做，也确实参与了不少，但它们不是我长期最想深耕的主线。
>
> 我长期更希望做的是 LLM 工程化和 Agent 平台化，比如如何设计更好的调度架构、如何通过评测体系驱动效果迭代、如何让大模型能力真正进入业务闭环。所以我现在会更关注这类岗位机会。

## 30 秒口语版

> 当前这 4 个月我主要做了 LLM Gateway、评测体系、开放问答和调度系统升级，也参与了不少线上问题排查和链路治理。这段经历让我补上了真实业务落地的工程视角。
>
> 但我也发现，当前岗位的重心更多在稳定性、排障和存量链路适配上，而我长期更希望深耕 LLM 工程化、Agent 架构、评测驱动迭代和 AI-native 产品闭环。所以现在不是急着离开，而是在谨慎看更匹配长期方向的机会。

## 答辩官追问：为什么才 4 个月就看机会？

推荐回答：

> 这个问题我也会认真考虑。当前这段经历虽然时间不长，但我已经参与了几个比较核心的模块，包括 LLM Gateway、评测体系、开放问答和调度架构升级，对车载语音大模型落地有了比较完整的理解。
>
> 我不是因为短期适应问题离开，也不是一定要马上走，而是在看是否有和我长期方向更匹配的机会。如果只是普通机会，我不会轻易变动；但如果岗位能让我在 LLM Agent、工程平台化和业务闭环上做得更深，我会认真考虑。

## 答辩官追问：你是不是稳定性有问题？

推荐回答：

> 我理解这个担心。我的上一段互联网大厂A公司经历并不是短期频繁变动，这次 4 个月看机会确实需要解释清楚。
>
> 我不是因为适应不了、绩效问题或者团队问题在看机会，而是这几个月做下来以后，我对自己长期想做的方向更清楚了。我希望下一段能选择得更慎重，所以也不是看到机会就动，而是只看和 LLM Agent、工程平台化、评测体系强相关的岗位。如果双方匹配，我会希望是一个可以长期投入的选择。

## 答辩官追问：问题排查和工程治理不也是 AI 落地的一部分吗？

推荐回答：

> 是的，我认同这也是 AI 落地很重要的一部分，而且这段经历也让我补齐了以前在探索型项目里相对少接触的线上工程视角。
>
> 只是从个人长期发展来看，我希望自己的主要工作重心不止停留在链路稳定性和问题定位上，而是能更多参与到 Agent 架构设计、评测体系驱动效果优化、模型能力和业务流程结合这些更核心的大模型应用建设里。

## 尽量避免的表达

不建议直接说：

- 当前工作不是 AI 落地。
- 当前公司 AI native 化很原始。
- 现在做的都是问题排查。
- 当前业务没前景。
- 入职后发现不符合预期。
- 想找更好的平台。

- 当前岗位的重心更多在链路稳定性、问题定位和工程治理上。
