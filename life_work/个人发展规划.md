## 三、主线 1：身体状态

### 3.1 目标分段（避免一刀切的激进节奏）

| 阶段 | 周期 | 节奏 | 备注 |
|---|---|---|---|
| 快速期 | 6 月 ~ 8 月 | 月减 2kg | 70 → 64，初期减脂窗口大，可激进 |
| 巩固期 | 9 月 ~ 11 月 | 月减 0.5~1kg | 64 → 63，避免快速反弹 |
| 维持期 | 2026.12 起 | 体重 63 ± 1 | 重心转向体态/力量 |

> 关键提醒：**进入 65kg 后必须放慢**，否则掉肌肉 + 反弹双输。

### 3.2 训练安排

训练日固定为 **周一 / 周三 / 周五 / 周日** 四天，全部为爬楼，无瑜伽垫/无氧替代，降低决策成本。

| 时段 | 内容 | 时长 |
|---|---|---|
| 周一 18:30~19:30 | 爬楼（公司楼梯） | 30~40min |
| 周三 18:30~19:30 | 爬楼（公司楼梯） | 30~40min |
| 周五 20:00~20:40 | 爬楼（居家公寓步梯）— 18:30 公司晚餐 → 19:30 到家休息 → 20:00 开练 | 30~40min |
| 周六 | 户外拍摄（Citywalk / 轻徒步，平均步数 1.5w+） | 4~6h |
| 周日上午 | 居家爬楼（公寓步梯/小区楼梯） + 拉伸 | 45~60min |

**周日训练菜单**：

| 类型 | 动作示例 | 时长 |
|---|---|---|
| 有氧（爬楼） | 公寓步梯/小区楼梯往返 | 35~50min |
| 拉伸（必做） | 大腿前后侧、臀肌、背部、肩颈 | 5~10min |

> 不再去健身房，也不再做瑜伽垫无氧组合。统一为「爬楼 + 拉伸」单一形态：免费、无通勤、上手零成本。

**爬楼执行细则**：
- 上楼用力，下楼乘电梯（保护膝盖）
- 心率控制 130~150bpm（中强度燃脂区间）
- 渐进：第 1~2 周 15min × 上 10 层 × 2 组 → 第 3 周后 30min × 上 10 层 × 3~4 组
- 公司常备一双有缓冲的运动鞋
- 周二 / 周四 / 周六晚：自由安排（写文案/修图/阅读/陪伴），不强制补训
- 4 天里若某天确有冲突（出差/团建/生病），当周不补训，保证 4 选 3 即可，避免加压

### 3.3 饮食原则（减脂 70% 靠吃）

**底层规则**：**睡前 3 小时不吃碳水**。按 23:00 入睡推算，**20:00 后不再摄入碳水**。

| 餐次 | 内容 |
|---|---|
| 早餐（通勤路上） | 便利店：酸奶 + 鸡蛋 + 香蕉 / 全麦三明治 |
| 午餐（食堂） | 一拳米饭 + 两拳青菜 + 一掌肉/鱼/蛋 |
| 晚餐（19:30 左右，工作日） | 正常吃，含碳水。爬楼日运动后吸收最佳 |
| 21:30 之后（到家） | 原则上不进食。如真饿：1 个水煮蛋 / 一杯无糖牛奶 / 黄瓜，**绝对不碰碳水和加工食品** |

**周末**：
- 周六（户外消耗大）：三餐自由吃，晚餐和女友外食可放松
- 周日：三餐正常 + 晚餐稍清淡，21:30 红线生效

## 四、主线 2：语音 AI 领域专家

### 4.1 什么叫"领域专家"

- 对领域有**系统性的知识地图**（架构、能力、链路、瓶颈）
- 能讲清楚**业内主流方案的差异和取舍**（豆包/通义/讯飞/小度/小米/理想/华为）
- 对**未来 1~2 年技术演进**有自己的判断（端到端 S2S、ToolCall 融合、多模态、车端推理）
- 在**自己的项目里能给出深度的决策叙事**

### 4.2 四个能力维度

#### 维度 A：知识地图持续完善
- 阵地：[car_voice_wiki](../car_voice_wiki/)
- 重点补齐：语义理解、大模型与 Agent、记忆链路、多模态、性能、数据
- 模板：每个能力点按「能力定义 + 业内方案对比 + 我们的方案 + 取舍」四段式
- 节奏：每周 1 个能力条目

#### 维度 B：行业动态跟踪

| 信息源 | 频次 | 时间投入 |
|---|---|---|
| 豆包/通义/Kimi/讯飞 等厂商技术博客、发布会 | 关键节点跟进 | 每月 2h |
| arXiv 实时语音/S2S/Voice Agent 论文（精读） | 每月 2 篇 | 每月 4h |
| 车机厂（理想/小米/华为/蔚来）语音助手体验 | 每季度 1 次 | 每季度 2h |

沉淀方式：在 `car_voice_wiki/行业动态/` 下每月一篇行业月报。

#### 维度 C：现有工作项目的深度叙事

## 五、主线 3：户外图文自媒体

### 5.1 定位

- **主赛道**：周末轻徒步 / Citywalk
- **辅助赛道**：装备 + 路线攻略类干货
- **不做**：短视频 / Vlog（剪辑成本高，挤占时间）

### 5.2 平台与频次

| 平台 | 角色 | 频次 |
|---|---|---|
| 小红书 | 主阵地（流量 + 涨粉） | 每周 2~3 篇 |
| 公众号 | 长文沉淀（路线攻略合集） | 每月 1~2 篇 |
| 即刻 / 微博 | 碎片日常（保持活跃感） | 随手 |

### 5.3 启动节奏（全新账号，从 0 开始）

```
6-8月    | 起号期：每周 2 篇，发够 30 篇打基础（不看数据）
9-11月   | 调优期：分析数据，找到爆款选题模板
12-2月   | 系列化：做 1~2 个系列 IP（如「周末城市出走」「半小时徒步路线」）
3-6月    | 商业化试水：接近 1w 粉时尝试品牌合作
7-12月   | 稳态期：保持每周 2 篇，沉淀个人 IP
```

**起号期关键动作**：
1. 找 20 个对标账号，**抄结构不抄内容**（标题模板、封面排版、正文节奏）
2. 前 30 篇不追数据，**先训练自己的产出能力**
3. 固定一个昵称 + 头像 + 简介，全平台统一

### 5.4 内容生产流水线

| 时间点 | 动作 |
|---|---|
| 周三晚 | 选题 + 路线规划（30min，可与女友一起讨论） |
| 周六上午-下午 | 出门拍摄（同时完成有氧主线） |
| 周六晚 | 图片精修（手机 LR / 醒图，30min） |
| 周日下午 | 写文案 + 排版 + 发布（90min） |
| 工作日午休前 / 通勤间隙 | 互动评论、看后台数据 |

**关键技巧**：一次出门产出 2~3 篇内容（不同角度、不同发布日），降低边际成本。

## 五附、辅助线：摄影进阶 & 化妆技巧 & 娱乐恢复

### 5A.1 摄影进阶学习

**起点判断**：非小白。已掌握基本机位选择、用光基础（顺光/侧光/逆光、白平衡）。

**待补能力**：
- **相机高阶**：测光模式、曝光锁定、自动对焦区域/追焦、闪光灯离机与补光、RAW 后期色彩管理
- **美姿指导**：女性人像引导（手部/眼神/腰线/小动作）、情绪调动、与场景互动
- **后期审美**：胶片质感、人像肤色、城市街拍调色

**学习节奏**：

| 时段 | 内容 | 时长 |
|---|---|---|
| 周二 22:00-23:00 | 视频课/电子书：相机高阶单点知识 | 60min/周 |
| 周日上午爬楼后 10:30-11:30 | 美姿手册研读 + 优秀案例拆解 | 60min/周 |
| 周六拍摄日 | 当天实战 1 个新技巧（不贪多） | 嵌入拍摄 |

**资源建议**（自行筛选，贵精不贵多）：
- 相机高阶：B 站「相机说明书/机身菜单」系列、官方教程
- 美姿指导：小红书「人像姿势」博主、《人像摄影摆姿宝典》、Pinterest 灵感库
- 后期：B 站 LR/达芬奇调色教程、海外摄影师 YouTube

**与主线 3 协同**：摄影学到的每一个新技巧 → 周六拍摄日实战 → 沉淀到自媒体内容，避免「只学不用」。

### 5A.2 女性化妆技巧学习

**起点判断**：零基础。目标是能针对各类脸型完成妆造设计与实施（实验对象：女友）。

**能力拆解**：
- **脸型诊断**：圆脸 / 方脸 / 长脸 / 心型 / 鹅蛋脸特征与修饰思路
- **妆造设计**：日常通勤 / 甜系女友 / 街拍大片 / 复古 / 清冷 等风格体系
- **实施技术**：底妆、修容高光、眼妆层次、眼线眼影、眉形设计、唇妆质地与颜色匹配
- **工具判别**：各类刷具/海绵用途、产品选择逻辑、主流品牌定位

**学习节奏**：

| 时段 | 内容 | 时长 |
|---|---|---|
| 周四 22:00-23:00 | 视频课：脸型分析 / 单项技术（眼妆/底妆/眉形） | 60min/周 |
| 周六出门前 30-45min | 实操：给女友上妆，当次拍摄主题配妆造 | 嵌入拍摄准备 |
| 拍摄后 | 微信记录 1 张妆面说明（用了什么 + 下次调什么） | 5min |

**资源建议**（贵精不贵多）：
- 脸型与妆造体系：B 站「化妆老师/人人都能学会」类系统课、《零基础化妆手册》
- 风格参考：小红书「妆面仿妆」博主、豆瓣「化妆」小组
- 工具评测：官方教程 + 中立评测 UP 主，避免只看广告

**与主线 3 / 5A.1 协同**：妆造 → 拍摄 → 后期 → 发布 形成闭环。化妆技巧是人像/街拍质感的上游输入，避免「后期补不了出片」。

**实践原则**：
- 与女友提前商量，取得同意后再实操；妆面以她舒适为优先
- 单次只调一两个变量（如仅换眼妆），便于归因
- 遇到她不舒适 / 不愿意时立即停手，不勉强

### 5A.3 娱乐与恢复

**定位**：解压、补充幸福感、为自媒体提供灵感与素材。**不是浪费时间，是必要的恢复**。

| 类型 | 时段 | 单次时长上限 |
|---|---|---|
| 打游戏 | 周五 21:00 后 / 周六晚精修后 | ≤ 2h |
| 电视剧 / B 站长视频 | 周五晚 / 周六晚 / 周日晚复盘后 | 单日 ≤ 1.5h |
| B 站碎片视频 | 工作日入家洗漱后 21:30-22:00 | 30min |

**边界**：
- 工作日 22:00 后不开新一集电视剧（避免拖到 23:30 后影响睡眠）
- 单次游戏 ≤ 2h，保护眼睛和睡眠
- 周末娱乐总量 ≤ 4h，不挤占周六户外拍摄和周日发布
- 看 B 站优先选摄影 / 户外 / 语音 AI 相关频道，娱乐顺带补充输入

## 九、执行保障机制

> 规划再精细，不执行等于零。以下机制的核心目标：**降低启动阻力 + 缩短中断恋期 + 视觉化进度**。

### 9.1 最小执行量原则

每个习惯设置「最低门槛」，状态再差也必须完成这个最小量，不允许“今天完全跳过”：

| 习惯 | 标准量 | 最小执行量（状态差/紧急时） |
|---|---|---|
| 爬楼 | 30~40min | 10min × 2 组（仅上下 5 层 × 2） |
| 摄影学习（周二） | 60min | 看 1 个 15min 视频 + 记 1 条笔记 |
| 化妆学习（周四） | 60min | 看 1 个 15min 视频 + 记 1 条笔记 |
| 自媒体写作 | 90min | 写 3 句文案框架 / 修 1 张图 |
| 知识地图 | 60min | 补充 1 个要点条目（15min） |
| 周六化妆实操 | 30-45min | 只给女友画一个局部（如仅眉形） |

> **核心理念**：最小量的目的不是给身体带来收益，而是 **保护“我是一个执行者”的身份认同**。做了 10min 和做了 0min 的差异，远大于 10min 和 40min 的差异。

### 9.2 两天规则

- 任何习惯**最多连续跳过 1 天**，第 2 天必须恢复（哪怕只做最小量）
- 应用场景：周一爬楼因加班未执行 → 周三必须执行（至少最小量）
- 如果连续 2 天未执行 → 第 3 天触发「紧急恢复」：当天最小量必须完成 + 晚上 5min 写下“连断原因 + 如何避免”

### 9.3 环境预设（降低启动阻力）

执行力的大敌是「启动成本」。提前 1 天把环境准备好，让「开始做」的摩擦力接近零：

| 习惯 | 环境预设动作 |
|---|---|
| 爬楼（工作日） | 运动鞋常放工位抽屉；18:25 闹钟提醒 |
| 爬楼（周五居家） | 到家就把运动鞋携到玄关；19:55 闹钟提醒 |
| 摄影/化妆学习 | 到家后立刻打开学习视频 APP 放桌面；手机开免打扰模式 |
| 周六拍摄 | 周五晚确认路线 + 相机充电 + 女友确认时间 |
| 周六化妆实操 | 周五晚将化妆工具包摆出来；确认当天妆造方案 |
| 自媒体写作 | 打开草稿文档放在第一屏；分屏置顶参考图片 |

### 9.4 视觉化追踪

人对「连续性」天然有执念（不想断链）。利用这个心理：

**工具选择**（任选其一，不贪多）：
- 纸质日历（贴在书桌旁）：每天打✅，强烈视觉反馈
- iOS「Streaks」APP / Android「开始记」：开屏就能看到今天待完成项
- Notion 习惯看板：周维度卡片，周日复盘时一眶全览

**追踪粒度**：
- 每日只追踪「是/否完成」，不追踪时长/质量（降低记录成本）
- 每周追踪维度：爬楼×4 / 摄影学习×1 / 化妆学习×1 / 自媒体发布×1 / 知识地图×1
- 周完成率 ≥ 80% 即为“执行合格”，不追求 100%（避免完美主义带来的全盘崩溃）

### 9.5 周复盘仪式（周日晚，15min）

已在时间模板中有「周日晚复盘」，这里给出具体执行框架：

**必答 3 个问题**：
1. 本周哪些习惯完成了，哪些中断了？中断原因是什么？
2. 下周有什么确定会干扰计划的事（加班/出差/约会）？提前调配。
3. 下周最想推进的 1 件事是什么？（不是全部，只选 1 件）

**不做**：
- 不写长篇复盘（三句话就够）
- 不自我批判（记录事实，不判断好坏）
- 不调整大计划（复盘是执行层面的，不是规划层面的）

### 9.6 断链修复策略

破功万难 —— 中断后如何重新开始，比中断本身更重要：

| 中断程度 | 恢复策略 |
|---|---|
| 1 天未执行 | 正常，不需要任何特殊操作，第 2 天照常做 |
| 2~3 天未执行 | 第 3 天必须执行最小量；晚上写 1 句中断原因 |
| 1 周未执行 | 不补欠债，不加量；只做一件事：下周一用最小量重新启动 |
| 2 周未执行 | 触发文档尾部「复盘小节」；分析是“环境问题”还是“动力问题”，对症调整 |
| 1 月未执行 | 该习惯可能需要重新设计（降低难度/换时段/简化内容），在月底回顾时处理 |

> **核心心态**：中断不是失败，放弃才是。每次中断后重启，都是在训练“从头开始”的能力——这本身就是执行力的核心。

### 9.7 月度打分（每月末，10min）

| 维度 | 评分规则 |
|---|---|
| 身体/爬楼 | 本月实际爬楼次数 ÷ 应爬次数，≥ 75% = A，50-74% = B，< 50% = C |
| 领域专家 | 本月新增知识地图条目数 + 发布输出数，≥ 4 = A，2-3 = B，< 2 = C |
| 自媒体 | 本月发布篇数，≥ 8 = A，5-7 = B，< 5 = C |
| 摄影/化妆 | 本月学习次数 + 实操次数，≥ 6 = A，3-5 = B，< 3 = C |

- 全 A/B → 计划稳定执行中，继续保持
- 出现 C → 分析原因（负荷过重？动力下降？环境变化？），下月调整 1 个变量
- 连续 2 月 C → 该维度可能需要降级或暂停，优先保护主线

### 9.8 动力维护

长期主义会疲劳，需要主动维护动力：

- **进度可视化**：每月拍一张体型对比照；知识地图填充百分比图；自媒体粉丝曲线
- **奖励机制**：周完成率 ≥ 80% → 周末娱乐时间不限制（正向强化）；连续 4 周合格 → 奖励自己一个小物件（如摄影配件、游戏皮肤）
- **身份叙事**：不要想“我要减肥”，而是想“我是一个每周爬楼 4 次的人” —— 身份驱动比目标驱动更持久
- **不比较**：只和上周的自己比，不和别人比；只看趋势，不看绝对值
