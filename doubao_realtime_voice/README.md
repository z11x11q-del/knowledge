## 核心观点速览

- **豆包视频通话与语音通话是一套核心架构**：共享多模态 LLM、对话管理、工具调用，差异仅在输入感知层与视频帧采样策略。
- **S2S 并非黑盒**：输出的是混合 token 流（speech/text/tool_call），由解码器实时分流。
- **工具调用在模型内部完成多意图拆解**：一次推理可输出多个 tool_call，并行派发执行。
- **半端到端是当前产品级主流**：一个 Transformer + 扩展词表 + 多通道输出，兼顾低延迟、情感保留、可观测性。
