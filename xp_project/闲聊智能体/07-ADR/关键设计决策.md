## 四、关键设计决策（ADR）

### 决策 1：笛卡尔组合冷启动——新 Combo 上线策略

**问题**：新模型或新 Prompt 上线时，没有历史数据，流量该给多少？给少了收敛慢，给多了风险大。

**决策**：采用**分阶段灰度 + MAB 动态调节**

```
阶段 1：1% 流量，人工观察 1 天，无明显劣化则进阶
阶段 2：5% 流量，跑 MAB（UCB 算法），自动判断是否继续放量
阶段 3：20% 流量，显著性检验通过后进入正式 AB 实验
阶段 4：AB 实验胜出 → 逐步放量至目标占比
```

**放弃的方案**：直接 50% 流量对打——风险过高，新 Combo 若存在人设漂移或安全问题会大面积影响用户。

---

### 决策 2：攒包首包延迟 vs TTS 自然度 trade-off

**问题**：首包越早下发感知延迟越低，但包太小（如只有半句话），TTS 语气断裂，体验差。

**决策**：**按输出类型区分首包策略**

| 输出类型 | 首包触发条件 | 原因 |
|----------|-------------|------|
| 情感回复 | 第一个完整短句（逗号/句号） | 情感回复短，快出首包体验好 |
| 信息回复 | 第一个完整长句（句号）或 30 Token | 信息回复需要语义完整 |
| 列表回复 | 等全量 | 列表残缺显示体验极差 |

**放弃的方案**：统一等完整段落——导致情感场景首字延迟超过 1s，用户感知明显。

---

### 决策 3：评测指标体系——主观指标如何量化

**问题**：闲聊质量天然主观，"有趣"、"自然"难以量化，怎么让评测可重复、可比较？

**决策**：**三层量化拆解**

```
第一层：行为指标（客观，无需人工）
  → 追问率、会话深度、负反馈率、点赞率

第二层：模型自动评分（半客观）
  → GPT-as-Judge 打多维度分 + 校准系数修正偏差

第三层：人工标注（主观，周期性校准）
  → 建立标注规范（4 个维度、5 级量表）+ 标注一致性检验（Kappa > 0.7）

结论：以行为指标为主决策指标，模型自评为辅助参考，人工标注为校准基准
```
