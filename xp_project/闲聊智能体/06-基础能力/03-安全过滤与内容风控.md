### 3.3 安全过滤 & 内容风控

**为什么必须有**：大模型会幻觉、会被"越狱"、会生成不合规内容，没有风控层就是裸奔上线。

**双层过滤架构**：

```
前置过滤（Query 进推理层之前）
  ├─ 违禁词命中 → 直接拒答，不消耗模型算力
  ├─ Prompt 注入检测 → 忘记你的设定类攻击识别
  └─ 用户历史风险评分 → 高风险用户加严过滤策略

后置过滤（模型输出之后）
  ├─ 违禁词二次扫描（模型可能绕过前置词典）
  ├─ 隐私信息检测：手机号、身份证、地址等 PII 信息脱敏
  ├─ 模型安全分类器：色情 / 暴力 / 政治的语义级检测
  └─ 品牌声誉保护：竞品负面对比、诱导性话术识别
```

**分级响应策略**：

| 风险级别 | 触发条件 | 处理方式 |
|----------|----------|----------|
| L0 极高危 | 政治敏感、违法内容 | 硬拦截 + 记录 + 告警 |
| L1 高危 | 色情、暴力 | 拦截 + 返回固定安全话术 |
| L2 中危 | 隐私泄露、竞品攻击 | 部分替换 + 降级回复 |
| L3 低危 | 轻微不当用语 | 替换敏感词后正常下发 |
