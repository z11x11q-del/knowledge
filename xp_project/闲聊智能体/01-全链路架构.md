## 一、全链路架构鸟瞰

### 1.1 架构分层

```
┌─────────────────────────────────────────────────────────────────┐
│  接入层（API Gateway）                                           │
│  鉴权 / 限流 / 协议归一 / 用户ID提取                             │
└───────────────────────────────┬─────────────────────────────────┘
                                ↓
┌─────────────────────────────────────────────────────────────────┐
│  预处理层                                                        │
│  ├─ Query 改写（纠错 / 指代消解 / 语义补全）                     │
│  ├─ Query 分类（意图路由：闲聊 / 任务型 / 拒答）                 │
│  └─ 安全过滤 · 前置（违禁词 / 注入攻击）                         │
└───────────────────────────────┬─────────────────────────────────┘
                                ↓
              ┌─────────────────┴──────────────────┐
              ↓ [闲聊路由]                    ↓ [联网查询路由]
┌─────────────────────────┐       ┌────────────────────────────┐
│  闲聊推理层             │       │  搜索增强层                   │
│  ├─ 上下文管理           │       │  ├─ 查询词提取 & 改写          │
│  ├─ 个性化画像注入       │       │  ├─ 多源检索调度                │
│  ├─ 缓存命中检查         │       │  ├─ 结果重排序 & 摘要          │
│  ├─ AB 分桶 → 模型×Prompt│       │  └─ LLM 综合生成（引用溯出）      │
│  │   笛卡尔路由          │       └──────────┬──────────────────┘
│  └─ LLM 推理（流式）     │               │
└────────────┬────────────┘               │
             └──────────────────────────────┘
             ↓
┌─────────────────────────────────────────────────────────────────┐
│  后处理层                                                        │
│  ├─ 安全过滤 · 后置（模型幻觉 / 内容违规检测）                   │
│  ├─ 干预层（规则 Override / 人工审核 / 黑白名单）                │
│  └─ 输出标准化 & 口语化（句式改写 / 长度控制 / 多样性）          │
└───────────────────────────────┬─────────────────────────────────┘
                                ↓
┌─────────────────────────────────────────────────────────────────┐
│  下发层                                                          │
│  └─ 攒包 & 动态替换（首包 / 续包 / 占位符注入 / TTS 触发）       │
└───────────────────────────────┬─────────────────────────────────┘
                                ↓
┌─────────────────────────────────────────────────────────────────┐
│  闭环层（异步）                                                  │
│  ├─ 评测采集（自动评测 + 人工标注）                              │
│  ├─ AB 指标统计 & 显著性检验                                     │
│  └─ 监控 & 告警（延迟 / 失败率 / token 消耗）                    │
└─────────────────────────────────────────────────────────────────┘
```

### 1.2 设计原则

| 原则 | 含义 |
|------|------|
| **可插拔** | 每一层都是独立组件，可按需开关；改写模块可整体绕过 |
| **全链路可观测** | 每个节点打 trace_id，延迟和错误从接入到下发全程可追 |
| **实验优先** | 所有关键决策节点都接 AB 实验框架，用数据驱动迭代 |
| **分级降级** | 模型/网络异常时逐级切换，不依赖单点稳定性 |
