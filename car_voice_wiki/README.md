# 汽车语音助手 Wiki

本目录用于沉淀汽车（车机）语音助手相关的知识、架构设计、技术方案与实践经验，作为系统化的 Wiki 知识库。

## 目录规划（建议）

- `01-产品与场景/`：产品形态、典型交互场景、用户画像
- `02-整体架构/`：端云协同架构、模块划分、关键链路
- `03-语音能力/`：唤醒、ASR、VAD、TTS、声纹、打断、拒识、判不停
- `04-语义与对话/`：NLU、DM、多轮、上下文、指代消解
- `05-大模型与Agent/`：LLM 接入、Function Call、Agent 编排、RAG、记忆链路（存储 / 消费 / 离线挖掘迭代）
- `06-多模态与车控/`：车控指令、导航、音乐、IOT、可见即可说
- `07-性能与稳定性/`：时延优化、弱网、降级、容灾、灰度
- `08-数据与评测/`：Badcase、评测集、AB、埋点、指标体系
- `09-安全与合规/`：隐私、合规、车规要求
- `10-工程与部署/`：服务化、发版、OTA、监控告警

## 使用说明

- 每篇文档采用 Markdown 编写，文件名以 `序号-主题.md` 命名，便于排序与检索。
- 同类文档按子目录归档，顶层 README 负责索引。
- 涉及项目经验的内容，可与 `xp_project/` 目录相互链接引用。
